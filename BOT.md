# Бот @RussiaTVHub_bot

Актуально на **25 октября 2026**. Бот встречает людей в личных сообщениях, открывает мини-апп, показывает справку и принимает благодарности Звёздами Telegram. Канал: [@RussiaTV_Hub_Live](https://t.me/RussiaTV_Hub_Live), мини-апп: `https://t.me/RussiaTVHub_bot/russiatv`.

## Где он работает

| Вариант | Файл | Когда использовать |
|---|---|---|
| **Cloudflare Worker (основной)** | `russia-bot-worker.js` | работает 24/7 и не зависит от компьютера. Webhook: `https://russia-bot-worker.dyaltd.workers.dev/hook` |
| Локально (polling) | `bot.js` | запасной вариант для отладки. **Нельзя запускать одновременно с воркером**: два способа получать обновления конфликтуют (Telegram отдаёт обновления только одному) |

Тексты и команды в обоих файлах одинаковые (8 языков: ru, en, bg, uk, de, fr, es, tr). При правке текста меняйте оба файла.

## Секреты (никогда не хранить в репозитории)

Задаются только в Cloudflare: Workers & Pages → `russia-bot-worker` → Settings → Variables and secrets (для `bot.js` — в локальном `.env`, он в `.gitignore`):

| Имя | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (тип Secret) |
| `ADMIN_ID` | числовой id администратора; только он может вызывать `/post` (узнать у @userinfobot) |

`.env.example` — публичный файл с заглушками: **настоящие значения в него не записывать**.
История: старый токен лежал в репозитории (в коде и в `.env.example`), поэтому его отзывали (`/revoke` в @BotFather). Если токен снова попал в открытый доступ — сразу `/revoke`, новый записать в секрет `BOT_TOKEN` и один раз открыть `/setup`.

## Первый запуск и смена токена

1. @BotFather → `/revoke` (при смене) → скопировать новый токен.
2. Cloudflare → воркер → Settings → добавить/обновить `BOT_TOKEN` (Secret) и `ADMIN_ID` → Deploy.
3. Открыть `https://russia-bot-worker.dyaltd.workers.dev/setup` — воркер сам зарегистрирует webhook (с секретным заголовком), команды, описание, короткое описание на 8 языках и кнопку меню «📺 Смотреть». Ожидаемый ответ: `"webhook": true, "menu": true`.
4. Проверить в боте: `/start`, `/help`, «⭐ Поблагодарить».

Webhook защищён: Telegram присылает заголовок `X-Telegram-Bot-Api-Secret-Token`, значение вычисляется из токена; запросы без него получают 403.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | приветствие (2 строки) и кнопки: «Открыть Russia TV Live» (мини-апп), «Сайт», «Помощь», «⭐ Поблагодарить» |
| `/start help`, `/help` | как смотреть, как показать на телевизоре (Cast в Chrome, AirPlay в Safari), контакт |
| `/start donate`, `/donate` | выбор суммы ⭐ 25 / 100 / 500 → счёт в Звёздах Telegram (валюта `XTR`, провайдер не нужен) |
| `/channels` | список каналов по темам |
| `/post` | **только `ADMIN_ID`**: публикует и закрепляет пост в канале с кнопками (приложение, сайт, помощь, спасибо) |

Оплата Звёздами работает в приложении Telegram (телефон, компьютер); в веб-версии может не открыться (об этом сказано в самом сообщении). Если счёт не создаётся, бот присылает причину отказа Telegram.

## Обновление списка каналов

При изменении числа/состава каналов поправьте `TOTAL` и массив `GROUPS` в `russia-bot-worker.js` и `bot.js` (сейчас 59 каналов, как в мини-аппе), затем задеплойте воркер и обновите закреплённый пост командой `/post` (старый пост удалить вручную).

## Деплой воркера

Через веб-интерфейс Cloudflare (Edit code) или API (как для воркеров потоков): загрузить `russia-bot-worker.js` как ES-модуль, **сохранив привязки** (`keep_bindings: secret_text, plain_text`), иначе секреты пропадут. После деплоя при необходимости снова открыть `/setup`.

Прямые ссылки на каналы из постов: `https://t.me/RussiaTVHub_bot/russiatv?startapp=<id канала>` (см. `CHANNEL_TEMPLATE.md`).
